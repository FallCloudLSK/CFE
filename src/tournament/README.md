# 2026春季盃 賽事管理（主辦方用）

- `host-ocuw9bre.html`：單一檔案（repo：FallCloudLSK/CFE 的 cfe-2026-spring/，不用 index 命名），已內嵌 LOGO 與截圖元件，可離線開啟。
- `players.txt`：放在 index.html 同一資料夾（GitHub Pages 同目錄）即會自動預載，一行一位選手，`#` 開頭為註解。
- `src/app.html`：原始碼；修改後執行 `python3 src/build.py host-ocuw9bre.html` 重新產生。
- `logo-full.png`：主視覺原圖；`logo.jpg`：頁面用縮圖。

## 資料保存
- 每次操作自動存在平板瀏覽器（localStorage），重新整理不會遺失。
- 「💾 備份」下載 JSON；換設備時用「📂 還原」載入。建議鎖定賽程、每輪結束、鎖定四強後各備份一次。
- 「↶ 復原」可回到上一步（最多 40 步，也可解除誤鎖）。

## 計分
- 單場勝 15 分；敗或和得「對手總勝場數」分（依賽制，和局雙方皆以敗方計）。
- 主分 = 15 × 勝場；輔分 = 敗/和場對手的總勝場合計；總分 = 主分 + 輔分。
- 奇數人數時每輪一人輪空，目前輪空視為兩勝（`BYE_AS_WINS`）。
- 同分加賽只在「涉及第1名」或「跨第4/5名」時要求輸入，點選依名次順序點選手。

## 已定案（FallCloud 2026-11-03）
- 輪空視為兩勝，同一人不重複輪空。
- 不做棄權功能，若發生由工作人員手動把後續場次登錄為 ╳。
- 同分加賽、四強賽和局依上述做法。
- 資料存在本地，搭配備份/還原/復原；每輪完成且尚未備份時，備份按鈕會高亮。
- 積分賽可跨輪登錄，不必等前一輪全部打完。
